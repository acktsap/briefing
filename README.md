# Briefing

정치·경제의 흐름을 읽기 위한 루틴 안내와 원자료 바로가기입니다. 시간대 구분 없이 헤드라인을 훑고, 중요한 사건을 고르고, 관련 숫자와 정책을 확인합니다.

각 자료에서 볼 항목, 비교할 기준, 숫자를 해석하는 방법을 안내합니다. 바로가기 목록과 상세 안내는 [사이트](site/index.html)에서 확인하세요.

## 로컬 실행

빌드·패키지 설치·서버 실행 없이 볼 수 있습니다. macOS에서 저장소 루트를 기준으로 실행하세요.

```sh
./open.sh
```

기본 브라우저에서 페이지가 열립니다.

## GitHub Pages 배포

1. 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
2. 변경사항을 `main` 브랜치에 푸시합니다.
3. **Actions → Deploy GitHub Pages**에서 배포 결과를 확인합니다. 수동 실행도 가능합니다.

예상 주소: https://acktsap.github.io/briefing/

워크플로는 `site/`만 배포합니다. 정적 자산은 상대 경로를 사용하므로 `/briefing/` 하위 경로에서도 동작합니다.

기사·통계를 수집하거나 복제하지 않습니다. 외부 링크는 새 탭에서 열리며, API 키·백엔드·데이터베이스를 사용하지 않습니다.
